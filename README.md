# 🏦 CoopSystem

> Sistema Integral para Cooperativas de Ahorro y Crédito.

---

## 📖 Descripción

CoopSystem es una plataforma web diseñada para la administración de cooperativas de ahorro y crédito.

El objetivo es ofrecer una solución moderna, segura y escalable para la gestión de asociados, cuentas, préstamos, caja, pagos y reportes.
